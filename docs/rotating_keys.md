# Rotating keys

The API and other keys the application uses are stored in the [jam.coop environment group](https://dashboard.render.com/env-group/evg-cm9dno0cmk4c739e4img) on render. They can be changed using the web interface.

## SECRET_KEY_BASE

Generate a new value using

   ./bin/rails secret

Save and restart the application. This will sign out existing users. Verify that the app still works and that you can [sign in](https://jam.coop/log_in).

## POSTMARK_API_KEY

Generate a new token using the [postmark web interface](https://account.postmarkapp.com/servers/11325378/credentials) for the production environment.

Save and restart.

Delete the old key in the postmark interface.

## POSTMARK_WEBHOOKS_TOKEN

Edit the bearer token for the webhook URL in the [postmark user interface](https://account.postmarkapp.com/servers/11325378/streams/broadcast/webhooks/14132729/edit).

It looks like

    Bearer <token>

Replace `<token>` here and the value of the POSTMARK_WEBHOOKS_TOKEN env var in render with a new value. A suitable value can be generated by

    openssl rand -hex 16

## CLOUDFLARE_TURNSTILE_SECRET_KEY

Login to the [cloudflare dashboard](https://dash.cloudflare.com).

Navigate to `Protect & connect > Application security > Turnstile`.

Click on the `jam.coop` widget and then `edit widget`.

Under `Widget Keys` click `Rotate Secret Key`.

In render replace the value of `CLOUDFLARE_TURNSTILE_SECRET_KEY` with the new value.

## STRIPE_SECRET_KEY

Visit the [stripe dashboard](https://dashboard.stripe.com) for jam.coop.

Search for `apikeys` and select `Developers > API keys`.

Under `Standard keys` use the `...` menu to rotate the `Secret key`. Chose a time to expire the old key and copy the new key.

In render replace the value of `STRIPE_SECRET_KEY` with this new key.

## STRIPE_ENDPOINT_SECRET

Visit the [stripe dashboard](https://dashboard.stripe.com) for jam.coop.

Search for and visit `webhooks`.

Under the `signing secret` section click the icon to rotate the key. Chose a time to expire the old key and copy the new key.

In render replace the value of `STRIPE_ENDPOINT_SECRET` with the new key.

## ROLLBAR_POST_CLIENT_ITEM_ACCESS_TOKEN

Open the [list of projects](https://app.rollbar.com/a/gofreerange/projects) in rollbar.

Click on `jam`.

Click on `project access tokens` in the sidebar.

Click the `Create New Token` button.

Create a new token with the `post_client_item` scope. Use the name `post_client_item`.

Copy the new token and replace the value of `ROLLBAR_POST_CLIENT_ITEM_ACCESS_TOKEN` in render.

The old `post_client_item` token can be expired once the application has been redeployed.

## ROLLBAR_ACCESS_TOKEN

Open the [list of projects](https://app.rollbar.com/a/gofreerange/projects) in rollbar.

Click on `jam`.

Click on `project access tokens` in the sidebar.

Click the `Create New Token` button.

Create a new token with the `post_server_item` scope. Use the name `post_server_item`.

Copy the new token and replace the value of `ROLLBAR_ACCESS_TOKEN` in render.

The old `post_server_item` token can be expired once the application has been redeployed.

## RAILS_MASTER_KEY

This variable is used to encrypt `credentials` files in Rails. We do not use this feature, so this token does not need to be rotated.
